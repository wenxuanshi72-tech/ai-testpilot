# Delivery Roadmap

Status: Phase 0 planning baseline. Later phases are planned, not implemented.

## Universal phase rule

Each phase uses a dedicated branch, may modify only its stated scope, produces an independently reviewable commit, and must pass its acceptance gate before the next phase branch is created. A failed gate keeps work in the current phase. Evidence and test results must be real; plans, examples, mocks, and incomplete provider calls are never reported as completed outcomes.

## Non-combinable gates

- Phase 5A precedes 5B; malformed or unattributed model output cannot feed case generation.
- Phase 7A must pass before the automation loop is claimed; Phase 7B must pass before browser automation is claimed.
- Evidence persistence in Phase 8 precedes formal bug and report generation.
- Regression compares immutable before/after runs; it never overwrites the original failure.
- Phase 15 is optional and cannot begin until the local loop is accepted.

## Version and maintenance policy

Protocol, prompt, schema, and exported-artifact versions evolve explicitly. Breaking changes require migration/replay planning. Each phase records its permitted paths during kickoff; discoveries outside that allowlist become a proposed follow-up rather than opportunistic changes.
